# Changelog

All notable changes to the **MD File Viewer** VS Code extension.

## 1.0.0

- **Custom editor** — `.md`, `.markdown`, `.mdx`, `.mdown` and `.mkd` files open
  in a full MD File Viewer editor by default (switch back with *Reopen Editor
  With…*).
- **Three view modes** — Preview, Split and Edit, selectable from the header and
  remembered across sessions.
- **WYSIWYG editing** — rich-text surface (Toast UI Editor) with a formatting
  toolbar.
- GitHub-style (GFM) preview with the Primer light/dark palette that follows your
  VS Code theme.
- Rendered preview with heading anchors, tables, task lists, blockquotes and
  fenced code blocks (syntax highlighting, language label and copy button).
- Document sidebar listing the folder's Markdown files.
- Smart link handling: external links open in the browser, local Markdown links
  open in the viewer.
- Formatting commands for the plain text editor (bold, italic, headings, lists,
  task list, quote, code block, link, image, horizontal rule) with `Ctrl+B` /
  `Ctrl+I` shortcuts.
- Status bar word / line / character counter.
- Settings for line breaks, GitHub styling, content width and the status bar.
